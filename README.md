# todo-er

My solution for the [Todo List project](https://www.theodinproject.com/lessons/node-path-javascript-todo-list) as part of the intermediate Javascript course from The Odin Project. 

[Start getting organized here](https://jshuhler.github.io/todo-list).

## features
- Create todos and associate them to a general Inbox project or create your own custom projects to track what you're doing. 
- Sort by todos due today, work that's overdue, view your completed work, or by any of your custom projects.
- Full edit functionality for your todos. 
- Persistent storage across page reloads using local storage.
- Utilizing several functions from the [date-fns](https://date-fns.org/) library to handle todo due dates and functions using those dates. 

## challenges
- This project required a level of organization that I have not needed up to this point in my learning experience. By the end of the work I would have chosen different structure for several of my key decisions - including how I associated a todo and project, how I designated the current sort, and my general module organization.
- Implementing using new libraries and local storage directly from reading and researching through documentation.
